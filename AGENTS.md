# Wisp

Wisp — личная база знаний в автономных HTML-страницах. Запуск, редактирование и проверки описаны в `README.md`.

## Работа с пользователем

- По умолчанию явно задавай `fork_turns="none"` при запуске подагента.
- Отвечай предельно кратко, при необходимости жертвуй грамматикой.
- Указывай ссылки только по прямому запросу пользователя.

## Соглашения

- Страницы хранятся в `html/`, общий шаблон — в `_templates/Заметка.html`. Командная утилита и локальный HTTP-сервер находятся в `scripts/wiki_html.py`, регрессионные тесты — в `tests/`.
- Тексты интерфейса и документация — по-русски.
- Артефакты изменения (снимки, прототипы, журналы проверок) — `.scratch/<имя изменения OpenSpec>/artifacts/<NN>-<slug>/`, живут до архивации изменения; исследовательские заметки для репозитория — `docs/research/`; скрипты, которые нужны и после влития, — `scripts/`.

## Agent skills

### Порядок работы

Для разработки Wisp следуй `CONTRIBUTING.md`: там описаны обсуждение, выбор маршрута по типу issue, исследования, разбиение epic, проверки и merge. Этот порядок заменяет прежний маршрут в `docs/agents/workflow.md`. Для работы над содержанием заметок используй `skills/wiki/SKILL.md`.

### Issue tracker

GitHub Issues через `gh` (`/ghub`), без MCP. Выбери один из шести типов по `CONTRIBUTING.md`. Тело issue берётся из `.github/ISSUE_TEMPLATE/`; `proposal.md` ссылается на issue строкой `Issue: #N`, PR закрывает его `Fixes #N`. См. `docs/agents/issue-tracker.md`.

PR: заголовок — по-английски, в повелительном наклонении (станет коммитом в `main`); текст — по-русски, по `.github/pull_request_template.md`.

### OpenSpec

Работа ведётся через OpenSpec (`openspec/config.yaml`). Текущие требования — `openspec/specs/<capability>/spec.md`; любое изменение поведения — изменение в `openspec/changes/<change>/` (`proposal.md`, `design.md`, `tasks.md`, дельты спек): `/opsx:propose` → `/opsx:apply` → `/opsx:archive`. Задачи, замеры и прототипы — пункты `tasks.md`, а не отдельные файлы в `.scratch/`.

### Domain docs

Один `GLOSSARY.md` и `docs/adr/` в корне. Термины — только из словаря, без синонимов. Если решение противоречит ADR, скажи об этом прямо, а не обходи молча.
