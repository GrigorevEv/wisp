Тема и пожелания — $ARGUMENTS. Если тема неясна из запроса и разговора, попроси указать её в `/wiki <термин>`.
Правь только автономные страницы в `/home/ev/code/personal/wisp/html/`. Главную обновляй командой `index`. Команды ниже вызывай через `python3 /home/ev/code/personal/wisp/scripts/wiki_html.py`.

## Выбор страницы

- Ищи по названию, расшифровке и `wiki-meta.aliases`, в `scst.html` также по заголовкам частей. Для запланированной темы возьми написание из `data-target`.
- Если тема уже есть, дай определение и имя файла. При запросе на изменение прочитай нужный фрагмент и поправь его на месте.
- Устройство и внутренние термины SCST добавляй частями в `scst.html`. Решения Engine и СХД, алгоритмы и разбор своего кода относятся к разделу «Работа».
- В разделе «Встречи» по просьбе правь только выжимку существующей встречи. Сохраняй транскрипт целиком, начиная с его заголовка.
- По умолчанию новая заметка — термин с тегом `термин` и синонимами. Для широкой темы или запроса «статья» либо «подробно» пиши развёрнутую статью.

## Текст и HTML

Пиши по-русски. В `p.sub` дай самостоятельное определение в 1–3 предложениях. После оглавления покажи конкретный пример. Новые термины объясняй при первом упоминании.
Сомнительные факты сверяй с первоисточником, детали SCST — с кодом в `/home/ev/code/aero/scst`.

- Новую страницу создай через `create "<имя>" --section "<раздел>" --summary "<первый абзац>" --heading "<заголовок>"`. Выбери раздел из `wiki-sections` на главной или «Входящие». Повтори `--heading` для каждой карточки, добавь нужные `--alias` и `--tag`, заполни карточки.
- При правке вступления обнови `meta[name="description"]`. При изменении разделов согласуй якоря, оглавление, навигацию и ссылки. Сохраняй авторский текст и схемы вокруг правки.
- Ссылки и обратные ссылки оформляй как `a.wl`, будущие страницы — как `span.wl.planned[data-target]`. Добавляй их по смыслу.
- В `references/html.md` открывай только нужный раздел, например «Большая заметка SCST», «Работа», «Схемы» или «Виджеты». Второго агента для вычитки подключай по просьбе, с `fork_turns="none"`.

## Завершение

После последней правки выполни команды по порядку, перечислив в `--edited` точные названия всех страниц, которые правил вручную.

```bash
python3 /home/ev/code/personal/wisp/scripts/wiki_html.py links --edited "<имя>"
python3 /home/ev/code/personal/wisp/scripts/wiki_html.py index --html-only
python3 /home/ev/code/personal/wisp/scripts/wiki_html.py check --html-only
```

Для новой страницы или изменения схемы, виджета либо вёрстки осмотри снимок изменённой области по разделу «Проверка страницы». Исправь найденные проблемы изменённых страниц и повтори нужные команды.
В ответе назови файл, суть изменения и результат проверки. Ссылку дай по просьбе. Для всей базы это `html/index.html`.
