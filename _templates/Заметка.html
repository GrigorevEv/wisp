Шаблон страницы базы знаний

Эталон стиля: здесь собраны все виды блоков. Каждая страница html/<заметка>.html устроена так же: общий CSS (<style id="wiki-css">) и движок схем (<script id="wiki-engine">) копируются из этого файла командой wiki_html.py sync, менять их нужно только здесь. Схемы рисуются по данным с явными координатами, без Mermaid, PlantUML и картинок.

Схема flow: дорожки, ромб, шаги рядом

Узлы и рёбра задаются данными WIKI.flow("svg-…", {…}). Номера на блоках совпадают с номерами шагов справа. Блок со ссылкой (href) ведёт на страницу заметки. Схема статичная: ничего не подсвечивается и не переключается. Интерактив — только в виджете (раздел «Виджет»).

Схема seq: обмен сообщениями

Участники — колонки, сообщения идут сверху вниз. blocks подсвечивают группу шагов (здесь — шаги, которые выполняет железо), notes — пояснения, {sep: "…"} — разделитель фаз, {gap: "…"} — пауза во времени. Варианты (variants, поле only и значения вида {"ok": …, "fail": …}) рисуются друг под другом, каждый со своей подписью.

Автомат состояний

Начало — k: "init", конец — k: "final". Петля задаётся точками via, подпись — lp: [x, y, "end"]. Шаги под схемой — section.card.stack.

Справка по движку

WIKI.flow(svgId, D)

D.vw, D.vh
размер холста. Координаты узлов — центры блоков.
nodes{ID: …}
k вид · x, y центр · w, h (высота считается по тексту) · t заголовок, s подпись (перенос — \n) · n номер-бейдж · chg оранжевая точка · al: "left" · href имя заметки · shape: "db" цилиндр · only вариант · q значок СМО вместо блока: src queue thr irq hold fork lost sink ctl step, текст рядом со значком, сторона — tp: "r" | "l" | "t" | "b", над или под боковой линией — "rt" | "rb" | "lt" | "lb"; many: true — стопка, таких несколько; own — метка «чьё» перед заголовком ("ядро", "пара"), oc: "all" — одна на всю систему, метка залита · tip — id элемента страницы (пункта пояснений): по клику на узел его текст показывается в окне под узлом
виды k
ext drv core disk hw thr q dec pause err note ghost focus init final
edges[…]
f, t узлы · fs, ts стороны t b l r · fo, to сдвиг вдоль стороны · via точки излома · straight · lab подпись, lp: [x, y, anchor] · cls: dash err chg hw, цвета видов заявок СМО data tm cfg sess (образец в легенде — border-color:var(--e-tm)) · mk: "none" | "both"
lanes[…]
вертикальные дорожки {x, w, y0, y1, c, t, left}; c: ext drv core dh svc hw
rows[…]
горизонтальные полосы во всю ширину {y0, y1, c, t, s}
variants
[{id, t}] — схема рисуется по разу на каждый вариант, друг под другом, с подписью vlabel: t; only: "id" у узла или ребра, значения вида {"id1": …, "id2": …}; элементы секции с data-only="id" переезжают под подпись своего варианта
legend
строится по использованным видам; {вид: "подпись" | false} переопределяет, false — без легенды; extra: [[подпись, style, класс]]

WIKI.seq(svgId, D)

parts[…]
{id, t, s, k, shape: "db", href}; колонки через D.colw (170)
msgs[…]
{f, t, lab, n, id, cls}; cls: dash err hw chg lost; f = t — сообщение себе; {sep}, {gap}, {note, over | right | left}; D.autonumber — номера по порядку
blocks[…]
{from, to, lab, k} — по id, n или ref сообщений (ref — номер без значка, для блоков); k: hw grp err alt
notes[…]
{at, over, text} — после сообщения at (0 — в начале)

Ошибки описания пишутся в консоль и в атрибут data-errors у <svg>; их ловит wiki_html.py check --render.
