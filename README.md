# Wisp

Личная база знаний в автономных HTML-файлах. Заметки и поисковый индекс хранятся локально в `html/`.

После клонирования скопируйте шаблон главной страницы в `html/`.

```sh
mkdir -p html
test -e html/index.html || cp _templates/Индекс.html html/index.html
```

Для чтения и поиска откройте `html/index.html` в браузере.

Чтобы изменить ширину списка заметок, потяните его правую границу мышью. Можно также выбрать разделитель клавишей Tab и нажимать ← или →. Браузер запоминает ширину. Для обновления существующей базы выполните `python3 scripts/wiki_html.py sync`.

## Папки и поиск

Во вкладке «База знаний» папки показаны над заметками на каждом уровне. Чтобы раскрыть папку, нажмите на её название. Поиск с любой вкладки охватывает папки, разделы и содержимое заметок всей базы.

Создать заметку в папке можно из корня проекта. Команда создаст и недостающие папки.

```sh
python3 scripts/wiki_html.py create "Шина данных" --folder hardware/cpu --section "Железо" --summary "Шина передаёт данные между устройствами." --heading "Пример"
python3 scripts/wiki_html.py index --html-only
```

Для пустой папки достаточно создать каталог внутри `html/` и выполнить `index --html-only`. При обновлении существующей базы сначала выполните `python3 scripts/wiki_html.py sync`, затем пересоберите индекс.

## Локальный сервер

Запустите сервер из корня проекта, чтобы перемещать, переименовывать и удалять заметки.

```sh
python3 scripts/wiki_html.py serve
```

Откройте адрес из терминала. Чтобы переместить заметку, перетащите её на название папки или нажмите на заметку правой кнопкой и выберите «Добавить в» → нужную папку. Меню доступно и в результатах поиска. Чтобы вернуть заметку на верхний уровень, выберите «Корень базы».

Для запуска в Docker используйте `docker compose up -d`. Данные хранятся в том же каталоге `html/`.

## После редактирования

Для страниц, изменённых вручную, передайте точные названия в `--edited`. Затем обновите поиск и проверьте базу.

```sh
python3 scripts/wiki_html.py links --edited "Название заметки"
python3 scripts/wiki_html.py index --html-only
python3 scripts/wiki_html.py check --html-only
```

Тесты запускаются командой `python3 -m unittest discover -s tests`. Для проверки отрисовки установите Chrome или Chromium и добавьте `--render` к команде `check`. Для импорта архива Markdown нужен пакет `markdown-it-py`.
