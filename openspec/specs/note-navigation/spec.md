# note-navigation Specification

## Purpose
Позволяет открывать заметки через папки на главной странице и находить материалы по всему содержимому базы знаний.

## Requirements

### Requirement: Папки перед заметками

Вкладка «База знаний» SHALL показывать папки из каталога базы перед заметками на каждом уровне вложенности. Папку можно раскрыть и свернуть.

#### Scenario: Пустая папка

- **WHEN** пользователь открывает обновлённую главную страницу базы с пустой папкой `hardware` и заметкой в корне
- **THEN** папка `hardware` видна выше заметки и доступна для раскрытия

#### Scenario: Вложенная заметка

- **WHEN** пользователь раскрывает `hardware`, затем вложенную папку `cpu`
- **THEN** видит в ней заметку и может открыть её в области чтения
- **AND** при сворачивании `hardware` вложенные строки скрываются

### Requirement: Поиск по всей базе

Поиск SHALL учитывать папки на любой глубине, названия разделов и подразделов базы, а также названия, синонимы, теги, заголовки и текст заметок независимо от выбранной вкладки и раскрытия папок.

#### Scenario: Совпадение в другой вкладке и во вложенной заметке

- **WHEN** запрос со вкладки «Встречи» совпадает с заголовком в заметке из свёрнутой папки и с текстом рабочей заметки
- **THEN** обе заметки доступны в выдаче
- **AND** переход по найденному заголовку открывает нужное место во вложенной заметке

#### Scenario: Поиск папки

- **WHEN** запрос совпадает с названием вложенной папки
- **THEN** выдача содержит эту папку, даже если она пуста
- **AND** выбор результата открывает путь к ней в дереве

#### Scenario: Поиск заметок по разделу

- **WHEN** запрос совпадает с названием раздела или подраздела в метаданных заметки
- **THEN** пользователь может открыть эту заметку из результатов, даже если искомых слов нет в её тексте

### Requirement: Работа с файлами во вложенной папке

Wisp SHALL поддерживать создание и чтение вложенных заметок, переходы между заметками и действия локального сервера по относительному пути внутри базы.

#### Scenario: Переименование заметки во вложенной папке

- **WHEN** пользователь переименовывает заметку в `hardware/cpu/` через контекстное меню
- **THEN** файл сохраняется в той же папке под новым именем, открывается из поиска и по обновлённым ссылкам

#### Scenario: Автономное чтение

- **WHEN** пользователь открывает главную страницу с диска и выбирает найденную вложенную заметку
- **THEN** открывается нужный файл и работают ссылки на главную и на заметки в других папках

### Requirement: Перемещение заметки в папку

На локальном сервере Wisp SHALL позволять перемещать существующую заметку перетаскиванием на папку и через пункт «Добавить в» контекстного меню заметки. Оба действия SHALL переносить один файл с его исходным именем и сохранять заголовок, раздел, содержимое и связи заметки.

#### Scenario: Перетаскивание на пустую папку

- **WHEN** пользователь перетаскивает заметку из корня на строку свёрнутой пустой папки `hardware`
- **THEN** после отпускания кнопки файл находится в `html/hardware/` и исчезает из корня
- **AND** пользователь видит заметку в целевой папке после раскрытия и может открыть её после перезагрузки

#### Scenario: Выбор вложенной папки через контекстное меню

- **WHEN** пользователь нажимает правой кнопкой на заметку в списке или поисковой выдаче и выбирает «Добавить в»
- **THEN** меню показывает корень базы и существующие папки, включая пустые, с различимыми путями для одноимённых папок
- **AND** выбор `hardware/cpu` перемещает туда заметку, а выбор корня позволяет вернуть её обратно

#### Scenario: Сохранение открытой заметки и ссылок

- **WHEN** пользователь перемещает заметку, открытую на конкретном заголовке
- **THEN** в области чтения остаётся тот же заголовок по новому адресу
- **AND** поиск выдаёт заметку один раз, ссылки из других заметок и исходящие ссылки и схемы ведут к прежним целям

#### Scenario: Занятое имя или исчезнувшая папка

- **WHEN** в целевой папке уже существует другой файл с таким именем либо папка исчезла до переноса
- **THEN** Wisp сообщает причину, сохраняет исходные файлы и согласованный поисковый индекс
