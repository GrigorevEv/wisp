# Design

## Context

Главная страница размещает список и область чтения в двух колонках CSS Grid. Заметка открывается в iframe. Кнопка сворачивания уже запоминает состояние списка в браузере.

## Goals / Non-Goals

Один разделитель управляет первой колонкой при чтении из файла и с локального сервера.

## Decisions

- Захват указателя позволяет продолжать жест за пределами разделителя. Пока кнопка нажата, iframe пропускает события указателя к главной странице.
- Выбранная ширина хранится отдельно от состояния сворачивания. При изменении размеров окна пересчитывается отображаемая ширина, чтобы при расширении окна восстановить предпочтение.
- Стили и скрипт разделителя принадлежат шаблону главной страницы. Команда `sync` переносит эти два блока в существующую страницу, сохраняя её разделы, поисковый индекс и остальную разметку.

## Risks / Trade-offs

Браузер может ограничивать локальное хранилище для файла. В таком случае ширина действует до закрытия страницы.
