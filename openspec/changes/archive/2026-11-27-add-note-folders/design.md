# Design

## Context

`page_paths()` собирает только файлы в корне. Индекс, локальный сервер и закладки используют имя файла. В шаблоне главной страницы `search()` отбирает результаты по активной вкладке. Пустые папки нельзя восстановить из списка страниц.

## Goals / Non-Goals

Файлы остаются самостоятельными HTML-страницами. Владелец базы сам выбирает, какие заметки хранить в `hardware/`. Метаданные раздела и расположение файла могут различаться.

## Decisions

- При индексировании обходить каталог `html/` рекурсивно. Хранить в существующем поле `file` путь относительно корня, а в отдельном блоке главной страницы — перечень папок, включая пустые. Оба блока доступны браузеру при открытии с диска. Корневые записи и старые закладки уже имеют подходящий формат.
- Строить дерево из этого перечня. Во вкладке «База знаний» показывать папки перед заметками на каждом уровне, сортировать каждую группу по имени. При открытии результата раскрывать его родительские папки. Для обычного просмотра сохранять распределение заметок по вкладкам и порядок встреч.
- При непустом запросе применять существующие правила поиска ко всем записям. Добавить в поисковые поля компоненты пути, раздел и подраздел. Для совпавших папок выводить путь, для совпавших заголовков использовать существующий якорь. Экранировать выводимые имена, кодировать компоненты URL.
- Добавить необязательный аргумент `create --folder` с путём относительно `html/`. При работе со ссылками вычислять адрес от папки исходной страницы. Передавать относительный путь через закладки, открытие в области чтения и контекстное меню. При переименовании создавать файл рядом с исходным, при удалении последней заметки сохранять папку в индексе.
- Обход и сервер должны исключать служебные каталоги, временные файлы операций и символические ссылки. Сервер обслуживает страницы внутри базы, сохраняет существующие проверки запросов на изменение.

## Risks / Trade-offs

- Папки с пробелами, кириллицей и одинаковыми конечными именами требуют сквозной проверки адресов на двух уровнях вложенности.
- Между обходом и записью можно захватить временные файлы другой команды. Использовать общий механизм блокировки и исключить промежуточные каталоги из индекса.
- В существующей главной странице есть личные данные. Обновлять через `sync` только нужные блоки и сохранить `wiki-sections`. При повторном обновлении результат должен совпадать.

## Migration Plan

На временной копии базы выполнить `sync`, `links`, `index --html-only`, `check --html-only` и проверить старую закладку, пустую папку и вложенную заметку. После проверки обновить личную базу и убедиться, что `hardware` видна над корневыми заметками.
