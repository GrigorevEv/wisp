# Spec Delta

## ADDED Requirements

### Requirement: Перемещение заметки в папку

На локальном сервере Wisp SHALL позволять перемещать существующую заметку перетаскиванием на папку и через пункт «Добавить в» контекстного меню заметки. Оба действия SHALL переносить один файл с его исходным именем и сохранять заголовок, раздел, содержимое и связи заметки.

#### Scenario: Перетаскивание на пустую папку

- **WHEN** пользователь перетаскивает заметку из корня на строку свёрнутой пустой папки `hardware`
- **THEN** после отпускания кнопки файл находится в `html/hardware/` и исчезает из корня
- **AND** пользователь видит заметку в целевой папке после раскрытия и может открыть её после перезагрузки

#### Scenario: Выбор вложенной папки через контекстное меню

- **WHEN** пользователь нажимает правой кнопкой на заметку в списке или поисковой выдаче и выбирает «Добавить в»
- **THEN** меню показывает корень базы и существующие папки, включая пустые, с различимыми путями для одноимённых папок
- **AND** выбор `hardware/cpu` перемещает туда заметку, а выбор корня позволяет вернуть её обратно

#### Scenario: Сохранение открытой заметки и ссылок

- **WHEN** пользователь перемещает заметку, открытую на конкретном заголовке
- **THEN** в области чтения остаётся тот же заголовок по новому адресу
- **AND** поиск выдаёт заметку один раз, ссылки из других заметок и исходящие ссылки и схемы ведут к прежним целям

#### Scenario: Занятое имя или исчезнувшая папка

- **WHEN** в целевой папке уже существует другой файл с таким именем либо папка исчезла до переноса
- **THEN** Wisp сообщает причину, сохраняет исходные файлы и согласованный поисковый индекс
