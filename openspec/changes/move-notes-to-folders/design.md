# Design

## Context

На главной у каждой строки заметки есть `data-file`, у папки есть `data-folder`, а список папок хранится в `wiki-folders`. Контекстное меню уже запоминает путь выбранной заметки. Сервер обрабатывает переименование и удаление под общей блокировкой с CLI и умеет откатывать частично опубликованные изменения.

## Goals / Non-Goals

Оба жеста выполняют одну операцию локального сервера. Существующая папка задаёт новое расположение файла. Название, раздел и дата редактирования содержимого сохраняются. При чтении с диска интерфейс указывает, что для переноса нужен локальный сервер.

## Decisions

- В контекстном меню показывать полный путь каждой доступной папки и «Корень базы». Текущую папку отмечать как выбранную. Выбор доступен с клавиатуры, Escape закрывает список. Использовать данные индекса, чтобы показывать и пустые папки.
- Начинать перетаскивание на строке заметки, подсвечивать строку папки под указателем. При отпускании брать путь из ближайшей папки, чтобы при вложенности срабатывала ровно одна цель. Обработчики ставить на список с учётом его перерисовок. Передавать только заметку, перетаскивание которой началось в Wisp.
- Расширить существующий PATCH заметки отдельным вариантом тела с полем `folder`. Пустая строка обозначает корень. После взятия блокировки проверить актуальность исходной заметки и существование целевой папки внутри базы. Перенос в текущую папку возвращает прежний путь. Использовать существующие проверки пути, конфликта имён и механизм публикации с откатом.
- Вычислять адрес каждой локальной ссылки относительно её исходного документа, затем относительно папки документа после переноса. Сохранить якоря и параметры, обновить ссылки на главную, форму поиска и `wiki-tips`. Перенос может требовать записи нового файла даже при совпадении его содержимого с исходным. Индекс и файлы обновлять как при переименовании.
- После ответа сервера восстанавливать состояние главной по новому пути, сохраняя запрос и якорь открытой заметки. Для существующей базы команда `sync` обновляет также разметку меню. Сейчас она переносит только стили и скрипты навигации.

## Risks / Trade-offs

- Папка может исчезнуть или целевой файл может появиться при открытом меню. Сервер проверяет назначение во время переноса и возвращает ошибку, которую интерфейс показывает пользователю.
- Папки с одинаковыми конечными именами, пробелами, кириллицей и знаком `#` требуют проверки полного пути и кодирования URL. Тесты используют вложенные папки и ссылки в обе стороны.
